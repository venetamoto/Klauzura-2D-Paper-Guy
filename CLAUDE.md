# Klauzura 2D — Paper Guy

2D-платформер в стиле школьной тетради (математика). Этот файл — память проекта для Claude
и для продолжения работы на другом устройстве. **После каждого заметного изменения обновляй этот файл**
(раздел «Журнал» внизу + затронутые разделы).

## Кто и как работает

- Автор уровня **Varvara** — общение **на русском**.
- **Весь текст внутри игры — на чешском**: комментарии в коде, `[Header]`, `[Tooltip]`, логи, надписи.
  Имена классов/полей/объектов — по-английски или как уже есть.
- **Код в «студенческом» стиле**: простые MonoBehaviour, `public` поля, без namespace, без `///` и почти без
  комментариев, без слоёв абстракций и без кода «на будущее». Неиспользуемые скрипты удаляем.
- **Не переименовывать сериализованные поля**, которые уже стоят в сцене (`groundCheck`, `target`, `levelBounds`,
  `hand`, `line`, `pathSource` …) — иначе в сцене слетят ссылки.
- Сцену **Ines** делает другой человек — её не трогать.

## Техника

- Unity **6000.5.6f1**, URP 2D, **только новый Input System** (`activeInputHandler: 1`).
- Ввод читается напрямую с клавиатуры/геймпада в `PlayerInputReader` (A/D, стрелки, пробел/W/↑, геймпад).
- Слои: `3 Ground` (платформы), `6 Collectible` (еда), `7 Player`, `2 Ignore Raycast` (триггеры-зоны).
- Build Settings: SampleScene, **Varvara**, **VarvaraKonec**.
- Сцены: `Assets/Scenes/Varvara.unity` (основной уровень), `VarvaraKonec.unity` (следующий уровень, пока почти пустой),
  `Ines.unity` (чужая), `SampleScene.unity`.

## Уровень Varvara

- Границы: x −16.5 … 63.5, пол y −5, потолок 24.84. Фон — белый лист (`Background_NotebookSheet`).
- Всё из **цветных квадратов** (текстуры автор пришлёт позже — заменить спрайты на объектах):
  - `Texty/text_platform_*` — розовые (текст), `Kresby/Drawing_platforms_*` — тёмные (рисунки),
    `Jidlo/Edible_1..35` — синие/голубые (еда), `Mistnost/*` — квадрат с зелёной полосой и дверью,
    `Sipky/*` — руки, рисующие кривые стрелочки-подсказки.
- Маршрут: старт внизу слева (−15, −4.4) → лесенка строк вверх → строка к графу → **спуск по графу кувырком**
  (старт графа (8, 15.5)) → подброс на строку → строки вправо → ступеньки → **зелёная полоса** → рука стирает →
  падение в **квадрат** (x 43…53.1, y −5…4.5) → рука рисует **дверь** → выход в дверь = **VarvaraKonec**.
- Граф оформлен как в тетради: голубая сетка, оси со стрелками и делениями, синяя кривая, подписи (`Graf_Kresba`).
- Проходимость проверена инструментом (см. ниже): прыжок ≈ 2.9 ед., подъём между платформами ≤ 2.4.

## Персонаж

- Объект `player`: Rigidbody2D, BoxCollider2D (0.8 × 2.05, offset (0, 0.525)), PlayerController2D,
  PlayerInputReader, PlayerAnimator. Дочерние: `GroundCheck`, `Postava` (`Noha_L`, `Noha_P`, `Plast`, `Hlava`).

  чёрный штрихованный плащ, тонкие ножки).
- Руки (`Assets/Art/Generated/Hand_Pencil.png`, `Hand_Eraser.png`) — pivot на кончике карандаша/ластика.

## Как вносить изменения в сцену (важно)

Unity обычно открыта, поэтому `.unity` руками не правим. Используем **одноразовый редакторский скрипт**
`Assets/SCRIPTS/Editor/<Имя>Once.cs`:
- `[InitializeOnLoad]` + `EditorApplication.update` ждёт, пока **не Play** и открыта сцена Varvara;
- ключ в `EditorPrefs` (новая версия ключа на каждое изменение), всё через `Undo`;
- в конце `EditorSceneManager.SaveScene(...)` (**сохраняем сами** — автор часто забывает Ctrl+S)
  и **удаляет папку `Assets/SCRIPTS/Editor`**, чтобы в проекте не оставалось инструментов.

## Инструменты (`Tools/`, вне Assets — Unity их не видит)

- `Tools/CompileCheck` — проверка, что скрипты компилируются без Unity: `dotnet build Tools/CompileCheck`
  (путь к Unity: свойство `UnityManaged`).
- `Tools/ArtGenerator` — консольная программа (.NET 10, Windows, System.Drawing), которая рисует весь арт и
  проверяет уровень: `dotnet run --project Tools/ArtGenerator -- <папка> <режим> [...]`
  - `hand` — рука с карандашом/ластиком; `hero` — части персонажа; `heroeat` — плащ сбоку, падение, поедание;
  - `level2` — проверка проходимости уровня + превью; `level2export` — данные для одноразового скрипта;
  - `pose`, `eatpose`, `sheet` — превью; `frames`/`extra`/`front`/`eat`/`concept` — старые инструменты для кадров из видео/концепта.
  - Раскладка уровня описана в `Level2.cs` (`Build()`, `Arrows()`), константы графа/старта там же.
